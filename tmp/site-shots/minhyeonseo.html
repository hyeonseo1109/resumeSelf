지원동기

사람과 기술을 이어주는 화면

저는 사용자가 길을 헤매지 않고 자연스럽게 다음 행동으로 이어갈 수 있는 화면이 좋은 서비스라고 생각합니다. 이러한 생각은 간호사로 근무하며 병원 전산 시스템을 사용하면서 더욱 분명해졌습니다. 같은 기능이라도 화면의 구조와 동선에 따라 업무 경험이 크게 달라지는 것을 체감했고, 이를 계기로 대학 시절 교양 수업에서 접했던 개발을 직업으로 선택하게 되었습니다.

이후 React와 Next.js를 중심으로 프론트엔드를 학습하며 팀 프로젝트를 진행했고, 2개월간의 인턴을 통해 실제 서비스 개발을 경험했습니다. 인턴 기간에는 모바일 웹뷰 기반 보상 서비스의 룰렛, 별자리, 타로 캠페인 등 실제 배포되는 기능을 구현했습니다. 백엔드 API가 준비되기 전에는 MSW를 활용해 개발을 이어갔고, 화면 구현에 필요한 API 구조를 정리해 제안하기도 했습니다.

인클루온은 키오스크, 출입 제어, IoT, 대시보드를 하나의 플랫폼으로 연결해 사용자의 이용 경험과 운영 효율을 함께 개선하는 서비스를 만들고 있습니다. 여러 기능이 실시간으로 연결되는 서비스일수록 사용자가 복잡함을 느끼지 않도록 돕는 UI가 중요하다고 생각합니다. 제가 경험해 온 사용자 중심의 화면 설계와 협업 방식이 이러한 방향과 잘 맞는다고 생각해 지원했습니다.

입사 후에는 프론트엔드 개발에만 머무르지 않고, 백엔드 개발자와 함께 시스템 전반을 이해하며 더 나은 사용자 경험을 고민하겠습니다. 사용자가 서비스를 이용하면서 불편을 의식하지 않을 만큼 자연스럽고 안정적인 화면을 만드는 개발자로 성장하겠습니다.

성장배경

경험이 방향이 되었습니다

대학 교양 수업에서 처음 개발을 접했을 때, 작성한 코드가 실제 화면으로 구현되는 과정이 흥미롭게 느껴졌습니다. 당시에는 전공에 집중하고 있었지만, 직접 무언가를 만들고 개선하는 즐거움은 오랫동안 기억에 남았습니다.

이후 간호사로 근무하며 병원 전산 시스템을 반복적으로 사용했습니다. 환자 정보 조회와 입·퇴원, 투약 등 대부분의 업무가 화면을 통해 이루어졌고, 같은 기능이라도 화면 구성과 동선에 따라 사용 경험이 크게 달라진다는 점을 체감했습니다. 이 과정에서 사용자가 서비스를 이용하는 흐름을 설계하는 일에 관심이 생겼고, 대학 시절 개발을 접했던 경험과 연결되면서 프론트엔드 개발자의 길을 선택하게 되었습니다.

부트캠프에서는 React와 Next.js를 중심으로 학습하며 두 차례 팀 프로젝트를 진행했고, 이후 프론트엔드 인턴으로 실제 서비스 개발을 경험했습니다. 처음에는 기능을 구현하는 데 집중했지만, 프로젝트와 인턴을 거치며 재사용 가능한 구조와 협업을 고려한 설계가 장기적으로 더 큰 가치를 만든다는 점을 배웠습니다.

앞으로도 사용자가 어떤 경험을 하게 될지를 먼저 고민하고, 이를 구현하기 위한 기술과 구조를 설계하는 개발자로 성장하겠습니다.

성격의 장단점

해결을 경험으로 남기는 사람

저의 가장 큰 장점은 문제를 해결하는 데서 끝내지 않고, 다음 프로젝트에서도 활용할 수 있는 방식으로 남긴다는 점입니다. 팀 프로젝트에서는 WebSocket 경험이 없는 팀원들을 위해 먼저 관련 기술을 학습하고, 공통 훅과 노션 문서를 작성했습니다. 이후 직접 사용 방법을 공유하며 팀원들이 쉽게 적용할 수 있는 구조를 만들었고, 다음 프로젝트에서는 예시만 제공한 뒤 팀원들이 직접 구현할 수 있도록 방식을 개선했습니다. 이 경험을 통해 개인이 빠르게 해결하는 것보다 팀 전체가 함께 성장할 수 있는 구조를 만드는 것이 더 중요하다는 점을 배웠습니다.

반면 인턴 초반에는 같은 코드를 반복해서 확인하다 보니 익숙해져, console.log 삭제나 테스트 코드, 파일명 규칙과 같은 사소한 부분을 놓치는 경우가 있었습니다. 이를 해결하기 위해 PR 전에 확인해야 할 항목을 체크리스트로 만들었습니다. 이후에는 같은 유형의 피드백을 반복해서 받는 일이 줄었고, 작업을 꼼꼼하게 마무리하는 과정도 자연스럽게 습관으로 자리 잡았습니다.

앞으로도 해결한 경험을 팀의 자산으로 남기고, 작은 부분까지 책임지는 개발자가 되겠습니다.

입사 후 포부

익숙한 화면 뒤의 개발자

제가 이루고 싶은 목표는 사용자가 서비스를 이용하면서 ‘왜 이렇게 불편하지?’라는 생각조차 들지 않는 화면을 만드는 것입니다. 화려한 기술보다 사용 경험을 먼저 고민하고, 기술은 그 경험을 자연스럽게 완성하기 위한 수단이라고 생각합니다.

입사 후에는 키오스크와 웹 서비스를 직접 경험하며 사용자의 동선을 이해하는 것부터 시작하겠습니다. 특히 여러 장비와 기능이 하나의 플랫폼으로 연결되는 서비스인 만큼, 화면 하나를 구현하더라도 전체 흐름을 함께 고려하는 개발자가 되고 싶습니다. 또한 백엔드 개발자와 적극적으로 소통하며 안정적인 API 연동과 유지보수가 쉬운 구조를 고민하겠습니다.

장기적으로는 단순히 많은 기능을 만드는 개발자가 아니라, 사용자가 별도의 설명 없이도 편안하게 이용할 수 있는 서비스를 만드는 개발자로 성장하고 싶습니다. 새로운 기술 역시 단순히 적용하는 데 그치지 않고, 실제로 사용자 경험에 도움이 되는지를 먼저 고민하겠습니다. 이를 바탕으로 인클루온의 서비스를 더욱 자연스럽고 편리하게 만드는 데 기여하겠습니다.
